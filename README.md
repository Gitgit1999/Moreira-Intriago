## Descripción del proyecto

Este portafolio personal fue desarrollado como parte de
la Actividad Integradora 1 de la asignatura Programación
de Sistemas Web de la Universidad ECOTEC.

El sitio presenta información sobre mi formación
académica, mi actividad profesional como policía,
mis habilidades tecnológicas y los proyectos
desarrollados durante mi proceso de aprendizaje.

La elaboración de este trabajo permitió aplicar
conocimientos de HTML y CSS, además de utilizar
GitHub para organizar los archivos y registrar
los avances realizados.

## Tecnologías utilizadas

- HTML5: estructura y contenido de la página.
- CSS3: diseño, colores y presentación visual.
- GitHub: almacenamiento y control de versiones.
- GitHub Pages: publicación del sitio web.

## Secciones del portafolio

1. Inicio: presentación personal.
2. Sobre mí: información académica y profesional.
3. Habilidades: conocimientos y capacidades.
4. Proyectos: trabajos realizados.
5. Contacto: formulario visual de comunicación.

## Organización del proyecto

- index.html: estructura principal del portafolio.
- styles.css: estilos y diseño de la página.
- img/avatar.svg: imagen representativa del estudiante.
- img/proyecto-portafolio.svg: imagen del proyecto.
- README.md: documentación del proyecto.

## Cómo visualizar el proyecto

1. Ingresar al repositorio de GitHub.
2. Descargar los archivos del proyecto.
3. Mantener index.html, styles.css y la carpeta img
   dentro de la estructura original.
4. Abrir index.html utilizando un navegador web.

También se puede visualizar directamente mediante
el enlace de GitHub Pages.
