# Portafolio personal

## Estudiante
MOREIRA INTRIAGO

## Descripción
Portafolio personal desarrollado para la Actividad Integradora 1
de la asignatura Programación de Sistemas Web.

El sitio se encuentra en su etapa inicial. Se incorporarán
la presentación personal, habilidades, proyectos y contacto.

## Tecnologías utilizadas
- HTML5.
- CSS3.

## Cómo visualizar el proyecto
1. Descargar los archivos del proyecto.
2. Mantener index.html y styles.css en la misma carpeta.
3. Abrir index.html con un navegador web.

## Organización
- index.html: estructura de la página.
- styles.css: estilos del sitio.
- img/: carpeta para las imágenes.
